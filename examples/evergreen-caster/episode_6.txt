Evergreen Compose connects Common Lisp view descriptions to native Android controls. The application supplies data, view functions, and callbacks. The shared runtime handles the controls. Scrolling runs on the Android user interface thread without calling Lisp for every frame. Application callbacks run on the Lisp worker. Start with one screen and one useful interaction. Then add a second screen, test Back, and give repeated list items stable identifiers. Small complete flows make good examples.
